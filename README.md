One razor-sharp line, 200 characters or fewer, that gets you out of a pointless
meeting: "Can't make the sync - I'm busy doing the thing this meeting was called
to discuss." The program writes it to `/output/entry.txt`; an AI judge pairs
excuses head to head and crowns the biggest laugh.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Node 22, standard library only, no network. Two runs produce byte-identical output.
